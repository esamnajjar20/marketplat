# لوحة التحديثات في الداشبورد

## التغيير
- استبدال عرض النشاط والمهام الدائم بلوحة قابلة للفتح والإغلاق بعنوان «التحديثات والنشاط».
- عند فتح اللوحة فقط يتم تركيب مكوّنات النشاط والمهام، وبالتالي لا يبدأ استعلام `/activity/dashboard` قبل الفتح.
- قائمة الإشعارات (`/notifications?limit=5`) لا تُطلب إلا بعد فتح اللوحة.
- النقر على إشعار غير مقروء يعلّمه كمقروء ويحدّث كاش الإشعارات والعدد.
- يبقى عداد الإشعارات العام في رأس الموقع فعالاً؛ لذلك قد يستمر طلب `/notifications/unread-count` عند فتح الداشبورد، وهو مطلوب لشارة الجرس في جميع الصفحات. اللوحة تشارك نفس React Query key ولا تنشئ طلب عدّاد منفصلاً.

## التحقق
تم فحص التغييرات نصياً ومراجعة مسارات الاستعلامات. لم تتوفر `node_modules` في نسخة المصدر، لذلك لم يتم تشغيل TypeScript الكامل أو Vitest أو بناء Next.js.
