# تقرير المرحلة الرابعة — تجميع لوحة التحكم

## النطاق

استهدفت لوحة التحكم `/dashboard`. كان مكوّنا «آخر النشاطات» و«يحتاج انتباهك» يطلبان بياناتهما عبر:

- `GET /activity?limit=8`
- `GET /sellers/me/attention`

وهما يظهران معًا في لوحة التحكم، لذلك أصبح من المناسب تقديم قراءة مجمعة مخصصة لهذه الشاشة. لا يشمل ذلك صفحة سجل النشاط الكامل أو لوحة المتجر.

## التنفيذ

أضيف المسار المحمي:

```http
GET /api/v1/activity/dashboard
```

ويعيد:

- آخر 8 نشاطات للمستخدم.
- عدادات المهام التي تحتاج انتباهه.
- حالة مستقلة لكل مصدر (`failures.activity` و`failures.attention`).

يُنفّذ الباك إند القراءتين بالتوازي عبر `Promise.allSettled`، حتى لا يؤدي فشل أحد المصدرين إلى إخفاء بيانات المصدر الآخر. المسار يستخدم `authenticate` و`CACHE.NONE` لأن المحتوى خاص بالمستخدم.

## الواجهة

- أضيف `activityApi.getDashboardOverview`.
- أضيف hook مشترك `useDashboardOverview` بمفتاح Query مرتبط بمعرّف المستخدم.
- يستخدم `RecentActivityFeed` و`SellerTodayTasks` الـ hook نفسه؛ React Query يشارك الطلب الواحد بينهما.
- تُحفظ بيانات الانتباه الناجحة في التخزين المحلي، وتُستخدم النسخة المحفوظة عند تعذر الاتصال.
- بقي `useMyAttention` متاحًا للوحة المتجر، وبقي `useMyActivity` مستقلًا لصفحة سجل النشاط والفلاتر.
- لا توجد تغييرات على نظام warming أو preheating.

## الأثر

في لوحة التحكم، يستبدل طلبان متزامنان بطلب واحد. عدد استعلامات قاعدة البيانات/الخدمات لا ينخفض؛ بل تُنفذ بالتوازي داخل طلب HTTP واحد. الفائدة الأساسية هي تقليل عدد الاتصالات ذهابًا وإيابًا، مع عدم تحميل بيانات إضافية في الصفحات الأخرى.

## التحقق

- تدقيق المرحلة الرابعة: 10/10.
- تحويل TypeScript/TSX المعدل إلى JavaScript للتحقق من الصياغة: 10/10.
- أضيف اختبار controller لتجميع المصدرين واختبار لعزل فشل أحدهما.
- تم تحديث اختبارات مكوّني النشاط والمهام لتستخدم hook المشترك، لكن لم تُشغّل Jest/Vitest.
- لم يُشغّل `tsc --noEmit` أو بناء Next.js/Express؛ `node_modules` غير موجودة في الأرشيف.

## اختبار بعد النشر

1. افتح `/dashboard` بحساب مسجل الدخول.
2. تحقق من ظهور طلب واحد إلى `/activity/dashboard` بدل `/activity?limit=8` و`/sellers/me/attention` من هذين المكوّنين.
3. تحقق من ظهور النشاط والمهام معًا.
4. اختبر فشل مصدر واحد وتأكد أن اللوحة الأخرى ما زالت تعرض بياناتها.
5. افتح لوحة المتجر وتأكد أن طلب `/sellers/me/attention` ما زال يعمل هناك.
6. اختبر فتح لوحة التحكم دون اتصال بعد وجود بيانات محفوظة؛ يجب أن تبقى مهام الانتباه متاحة من الكاش، بينما يعرض النشاط حالة تعذر التحميل بدل إظهار قائمة فارغة مضللة.
