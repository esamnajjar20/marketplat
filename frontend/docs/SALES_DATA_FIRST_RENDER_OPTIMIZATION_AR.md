# تحسين زمن ظهور بيانات المبيعات

## التغيير
- إضافة `CACHE_TTL.salesList` (15 ثانية) لقائمة المبيعات، مع الإبقاء على `keepPreviousData` حتى لا تختفي القائمة عند الانتقال بين الصفحات.
- إضافة `CACHE_TTL.salesData` (60 ثانية) لملخص المبيعات والرسم البياني والمقارنة؛ كانت هذه الاستعلامات بلا `staleTime` صريح، وبالتالي تعتبر stale فورًا وتُعاد عند mount وفق إعدادات TanStack Query.
- تخزين إعدادات التكلفة ومنتجات التكلفة 5 دقائق لأنها بيانات مرجعية بطيئة التغير. عمليات تعديل التكلفة تبطل مفتاح `sales.costProducts`، وعمليات البيع/المرتجعات/الدفعات تبطل عائلة `sales.all`.

## لماذا هذا آمن؟
البيانات المجمعة لا تصبح ثابتة: عمليات البيع والمرتجعات والدفعات ما زالت تبطل عائلة المبيعات. مدة الصلاحية تمنع إعادة جلب غير ضرورية عند التنقل بين تبويبات المبيعات خلال جلسة قصيرة. لا تتغير حسابات المبالغ أو استعلامات قاعدة البيانات أو صلاحيات المستخدم.

## حدود الإثبات
هذا تحسين لسلوك إعادة الاستخدام في React Query، وليس قياسًا لزمن الخادم أو LCP. يجب قياس Network ووقت ظهور القائمة على جهاز حقيقي قبل/بعد النشر. لا توجد ادعاءات رقمية عن مقدار التحسن دون بيانات ميدانية.
