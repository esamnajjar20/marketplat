# Offline Hub — Payments & Cards UI/UX Pass

## Scope

- دمج جهات الدفع وبطاقات النت داخل `/offline` كتَبويب للمستخدم المسجّل.
- إبقاء `/saved-payments` مسارًا متوافقًا مع رابط رجوع واضح إلى الـHub.
- تحسين العرض المكتبي، الحالات الفارغة، البحث، أزرار الإجراءات، ووضوح التخزين المحلي.

## UX changes

- تبويب مستقل للدفع والبطاقات داخل Offline Hub.
- بطاقات إحصائية لعدد جهات الدفع والبطاقات وحالة التخزين المحلي.
- شبكة بطاقات مزدوجة على الشاشات الكبيرة.
- شريط أدوات أوضح لكل نوع محفوظات.
- إخفاء حقول كلمات المرور أثناء الإدخال.
- تحسين semantics للتبويبات وtabpanel.
- تنبيه واضح بعدم حفظ بيانات حساسة على جهاز مشترك.

## Compatibility

- لم يتم تغيير API أو storage schema أو USSD behavior.
- لا تظهر بيانات الدفع للزائر داخل تبويب الـHub؛ التبويب متاح بعد hydration للمستخدم المسجّل فقط.
