# سياسة بدون GPS — فلاتر البحث

المنتج **لا يستخدم GPS** في مسار البحث والفلاتر.

## ما أُزيل من واجهة الفلاتر
- زر / preset «قريب مني»
- طلب صلاحيات الموقع
- ترتيب «الأقرب» (`sort=distance`)
- كتابة `lat` / `lng` / `radius` في الـ URL من الواجهة

## الموقع المعتمد
- اختيار **مدينة** من القائمة فقط (`CITIES`)

## روابط قديمة فيها lat/lng
- عند فتح الـ Sheet تُمسَح من المسودة
- عند «عرض النتائج» لا تُعاد كتابتها
- شارات Active Filters لا تعرض «قريب مني»

## Backend
- دعم lat/lng في API يمكن أن يبقى للتوافق؛ الواجهة لا تستدعيه.

## Feature flag
- أبقِ `FEATURES.GPS_LOCATION = false` إن وُجد في المشروع.
