# تقرير المرحلة 11 — تحديث الصفحة الرئيسية عند عودة الاتصال

## النطاق
- تحديث قسم اكتشاف السوق وقسم المتاجر عند الانتقال المؤكد من عدم الاتصال إلى الاتصال.
- منع تداخل طلبات التحديث داخل كل قسم.
- الحفاظ على آخر محتوى ناجح ظاهرًا عند فشل التحديث.
- إبقاء القصص خاصة بالجلسة الحالية وفي الذاكرة فقط، ومسحها عند تغيّر الجلسة حتى لا تظهر بيانات حساب سابق.
- الاستمرار في استخدام SQLite cache العام للمتاجر والتوصيات العامة دون إضافة مخزن أو نقطة API جديدة.
