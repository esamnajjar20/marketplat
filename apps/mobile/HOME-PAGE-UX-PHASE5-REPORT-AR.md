# تقرير المرحلة الخامسة — توحيد بطاقات الصفحة الرئيسية

## الهدف
تحسين وضوح بطاقات الإعلانات والاكتشاف والمتاجر والقصص، وجعل فشل الصور لا يترك عناصر مكسورة بصريًا.

## التعديلات
- توحيد الارتفاع الأدنى لمنطقة صورة/محتوى بطاقة الإعلان، وتقليل عرض الصورة قليلًا لإتاحة مساحة أفضل للنص على الشاشات الضيقة.
- إبقاء زر المفضلة فوق الصورة بوضوح عبر ترتيب الطبقات، مع مساحة لمس مناسبة.
- تثبيت الارتفاع الأدنى لبطاقات الاكتشاف والمتاجر كي تبدو البطاقات المتجاورة أكثر اتساقًا.
- التعامل مع فشل صور المتاجر وصور/أفاتارات القصص والرجوع إلى العنصر البديل بدل صورة مكسورة.
- إضافة فحص ثابت خاص بالمرحلة الخامسة إلى سكربت الاختبارات.

## حدود التحقق
تم التحقق عبر سكربتات الفحص الثابتة وصحة JSON في `package.json`. هذا لا يُعد اختبار تشغيل على جهاز، ولا يؤكد نجاح بناء Expo أو فحص TypeScript الكامل.
