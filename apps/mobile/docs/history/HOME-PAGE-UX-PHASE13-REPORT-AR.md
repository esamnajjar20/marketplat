# تقرير المرحلة 13 — عزل بيانات الصفحة الرئيسية حسب الحساب

## التغييرات
- تمييز لقطة توصيات الصفحة الرئيسية بأنها عامة أو مخصصة للحساب.
- السماح بعرض التوصيات المخصصة فقط عندما يطابق مالك اللقطة معرّف الحساب النشط.
- إبقاء التخزين العام للتوصيات العامة عند عدم تسجيل الدخول فقط، وعدم حفظ التوصيات المصادق عليها في التخزين العام.
- ربط قصص الصفحة الرئيسية بمعرّف الحساب الذي جلبها، وعدم عرضها إذا تغيّر الحساب أو انتهت الجلسة.
- إبقاء بيانات المتاجر العامة في التخزين العام، لأنها غير مرتبطة بجلسة مستخدم.
- إضافة فحص ثابت للمرحلة 13 إلى سكربت الاختبارات.

## التحقق
تم تشغيل فحص المرحلة 13 وفحوص الصفحة الرئيسية للمراحل 10–12، إضافة إلى فحوص الأقسام ذات الصلة. هذه فحوص ثابتة وليست اختبارًا على جهاز فعلي. لم يتم تأكيد بناء Expo الكامل أو فحص TypeScript الكامل.
