# تقرير صفحات المتجر للموبايل

## ما تم تنفيذه
- صفحة المتجر العامة بتصميم محدث: الغلاف والشعار وبيانات التواصل وإحصاءات المتابعة والزيارات.
- تبويبات المنتجات، التقييمات، وعن المتجر.
- متابعة/إلغاء متابعة المتجر مع حالة محفوظة من API وتراجع آمن عند فشل الطلب.
- إرسال تقييم من 1 إلى 5 مع تعليق اختياري حتى 500 حرف؛ الخادم هو المرجع في منع التقييم المكرر ومنع تقييم المتجر الشخصي.
- إدارة المتجر: رفع الشعار والغلاف عبر Expo Image Picker وواجهات `/stores/me/logo` و`/stores/me/cover`، مع رمز CSRF عند توفره.
- صفحة إحصاءات تعتمد على `/stores/me/analytics` دون اختلاق إيرادات أو أرقام مبيعات غير متاحة.
- صفحة المتاجر المتابَعة من `/stores/me/followed`.
- إضافة اختبار تحقق ثابت وربطه بـ `npm test`.

## حدود التحقق
اختبار التحقق الثابت لا يثبت نجاح بناء TypeScript أو رفع الصور أو صلاحيات الخادم. يجب تثبيت التبعيات، وتشغيل `npm test` و`npm run type-check`، ثم تجربة التطبيق على خادم اختبار وحسابات مختلفة قبل الإنتاج.
