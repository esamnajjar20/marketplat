# تحسين الصفحة الرئيسية متعددة الأقسام — MarketPlat

## ما تم تنفيذه

- استبدال قائمة الاختصارات الطويلة بثمانية اختصارات مضغوطة: الإعلانات، المتاجر، المنتجات، الخدمات، طلبات السوق، القصص، البائعون، وكل الأقسام.
- إضافة قسم «اكتشف من السوق» يجمع الإعلانات والمنتجات والخدمات في شريط بطاقات أفقي واحد.
- استخدام نقطة API مختلطة واحدة لهذا القسم، مع توزيع العناصر بين الأنواع حتى لا يهيمن نوع واحد على العرض.
- عدم تعطيل الصفحة الرئيسية إذا فشل تحميل قسم الاكتشاف الاختياري.
- تقليل عرض تصنيفات الرئيسية إلى ستة عناصر، وتوجيه رابط «كل الأقسام» إلى صفحة التصنيفات بدل مسح فلاتر الإعلانات بصمت.
- تحديث نص البحث ليعكس البحث عن الإعلانات والمتاجر والمنتجات والخدمات.
- إضافة فحص آلي للتحقق من وجود الأقسام الأساسية وربطه بأمر اختبار تطبيق الموبايل.

## الملفات

- `apps/mobile/app/index.tsx` — تعديل الصفحة الرئيسية.
- `apps/mobile/src/features/discovery/HomeMarketplaceHighlights.tsx` — مكوّن جديد لبطاقات المحتوى المختلط.
- `apps/mobile/scripts/verify-homepage-multi-section.mjs` — فحص آلي جديد.
- `apps/mobile/package.json` — ربط الفحص بأمر `test`.
