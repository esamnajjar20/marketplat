# المرحلة 3 — توحيد القوائم وشاشة الإضافة

## ما تم تنفيذه

### 1. مكوّنات سوق مشتركة (`src/components/MarketCards.tsx`)
- `CatalogCard` — بطاقة قائمة موحّدة (منتج / خدمة / متجر)
- `AdCard` — بطاقة إعلان أفقية (جاهزة للرئيسية لاحقًا)

### 2. `SearchBar` في MobileUI
شريط بحث موحّد (أيقونة + إدخال + مسح + زر بحث)

### 3. قوائم التصفح
| الشاشة | التحسين |
|--------|---------|
| `products.tsx` | AppHeader + SearchBar + CatalogCard + حالات موحّدة |
| `services.tsx` | نفس النمط |
| `stores.tsx` | نفس النمط |
| `requests.tsx` | Chip للفلاتر + حالات موحّدة + SectionCard |

### 4. شاشة الإضافة (`add.tsx`)
مجموعتان واضحتان عبر `SectionHeader` + `ListRow` بدل بطاقات عشوائية.

## المنطق المحفوظ
الكاش، الصفحات، البحث، المعاملات (storeId/categoryId) لم تُغيَّر وظيفيًا.
