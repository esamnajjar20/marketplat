# المجموعة السادسة — تصميم المبيعات والطلبات

## الملفات المعدلة
- `app/my-sales.tsx`: تحسين بطاقات الملخص وفلاتر الفترات وبطاقات المبيعات والمسافات.
- `app/seller-orders.tsx`: تحسين تباعد قائمة الطلبات الواردة وحجم العناوين والأزرار.
- `app/orders.tsx`: تحسين بطاقات طلبات المشتري وأزرار الانتقال لإدارة الطلبات.
- `app/order-checkout.tsx`: تحسين بطاقة المنتج وحقول نموذج الاستلام والمسافات.
- `app/orders/[id].tsx`: تحسين عرض تفاصيل الطلب وبطاقة التفاصيل وأزرار تغيير الحالة.
- `app/sales/[id].tsx`: تحسين بصري محدود لعنوان قسم تفاصيل البيع.
- `app/sales/[id]/receipt.tsx`: تحسين التسلسل البصري للفواتير والمسافات بين بنودها.

## نطاق التغيير
هذه المجموعة تركز على طبقة العرض والأنماط فقط، ولا تقصد تغيير واجهات API أو قواعد الطلبات أو حالات الدفع أو منطق المصادقة. حافظنا على مسارات الملفات كما هي داخل المشروع.

## التحقق
- تم التأكد من وجود الملفات السبعة في الأرشيف بعد نسخها من نسخة العمل.
- تمت مراجعة تعديلات الأنماط نصيًا.
- لم يتم تشغيل TypeScript أو بناء Expo أو اختبار التطبيق على جهاز؛ اعتماديات المشروع غير مثبتة في بيئة العمل. يجب تشغيل `npx tsc --noEmit` / أو سكربت التحقق المعتمد للمشروع بعد تثبيت الاعتماديات، ثم تجربة تدفق الطلب والشراء في بيئة اختبار.
