# تقرير المرحلة 12 — دورة حياة التخزين المؤقت للصفحة الرئيسية

## التغييرات
- استخدام `readPublicCacheEntry` لقراءة وقت حفظ البيانات مع المحتوى.
- تحديد نافذة حداثة مدتها 3 دقائق لتوصيات السوق العامة و10 دقائق لقائمة المتاجر العامة.
- تجنب طلب الشبكة عند فتح الصفحة إذا كانت النسخة العامة المحفوظة حديثة.
- فرض تحديث عند اكتشاف عودة الاتصال بعد انقطاعه، حتى لو كانت النسخة المحفوظة ضمن نافذة الحداثة.
- إبقاء قصص المستخدمين خاصة وفي الذاكرة فقط، وعدم وضعها في التخزين العام.
- إضافة فحص ثابت للمرحلة 12 إلى سكربت الاختبارات.

## التحقق
شُغّل فحص المرحلة 12 وفحوص الصفحة الرئيسية للمراحل 3–11. هذه فحوص ثابتة للكود وليست اختبارًا على جهاز حقيقي. لم يتم تأكيد بناء Expo الكامل أو فحص TypeScript في هذه المرحلة.
