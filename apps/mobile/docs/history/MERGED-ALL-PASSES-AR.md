# دمج كل مراحل التعديل — MarketPlat Mobile

أرشيف موحّد لكل ملفات الموبايل المعدّلة عبر المراحل السابقة.

## المراحل
1. Lightweight: AppImage, listPerformance, zod
2. FlatList لكل شاشات القوائم
3. homeFormatters, useOnlineResync, validation
4. useHomeAds/useHomeServices, ألوان الهوية, offline UX, expo-build-properties

## تثبيت
```bash
cd apps/mobile
npm install
npx expo install expo-image expo-build-properties
npm install zod
npm run type-check
```
