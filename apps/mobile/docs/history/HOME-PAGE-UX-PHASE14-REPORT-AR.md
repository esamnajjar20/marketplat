# تقرير المرحلة 14 — منع فقدان التحديث عند تبدّل الاتصال

## التغييرات
- إضافة آلية تجميع للتحديث الإجباري إذا عادت الشبكة بينما يوجد طلب تحديث قيد التنفيذ في قسم اكتشاف السوق أو قسم المتاجر والقصص.
- إعادة تنفيذ التحديث الإجباري بعد انتهاء الطلب الحالي بدل إسقاط حدث عودة الاتصال بسبب وجود طلب قيد التنفيذ.
- منع نتيجة طلب متاجر قديم من الكتابة إلى التخزين العام بعد تنظيف تأثير React المرتبط بالجلسة أو الحساب.
- الحفاظ على حراسة `active` لمنع تحديث الواجهة بعد إلغاء التأثير، وعدم إضافة طلبات API أو مكتبات جديدة.
- إضافة فحص ثابت للمرحلة 14 إلى سكربت `test`.

## التحقق
تم تشغيل فحوص المرحلة 14 وفحوص الصفحة الرئيسية للمراحل 3–13، إضافة إلى فحوص الأقسام ذات الصلة والتحقق من سلامة `package.json` وملف ZIP. هذه فحوص ثابتة للكود؛ لا تمثل اختبارًا على جهاز فعلي، ولم يتم تأكيد بناء Expo أو فحص TypeScript الكامل.
