# المجموعة الثالثة — تصميم صفحات التفاصيل

## الملفات المعدّلة
- `app/ads/[id].tsx`: تحسين عرض معرض الإعلان، بطاقة التفاصيل والوصف وأزرار التواصل.
- `app/products/[id].tsx`: تحسين عرض الصور، إبراز السعر والعنوان، وتوحيد شكل بطاقات وأزرار الإجراءات.
- `app/services/[id].tsx`: تحسين صورة الخدمة وبطاقة العنوان والسعر وزر الطلب السفلي.
- `app/stores/[id].tsx`: تحسين الغلاف وبطاقة المتجر وبطاقات المنتجات.

## حدود التعديل
التغييرات مركزة على الأنماط والمسافات والتسلسل البصري. لم تتعمد تغيير مسارات API أو منطق الطلب والمراسلة والمفضلة والتبليغ أو التنقل.

## التحقق
تم فحص التغييرات نصيًا والتأكد من وجود تعريفات الأنماط وعناصر الشاشات الأساسية في الملفات الأربعة. لم يتم تشغيل فحص TypeScript أو Expo أو اختبارات الجهاز؛ يجب تنفيذها في بيئة المشروع التي تحتوي على التبعيات قبل اعتمادها للإنتاج.
