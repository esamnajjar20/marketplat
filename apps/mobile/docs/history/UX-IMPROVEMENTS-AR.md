# تحسينات UX الشاملة

## أهداف
تقليل الضوضاء البصرية، تغذية راجعة أوضح، حالات تحميل أفضل، ووعي بحالة الاتصال.

## ما تم تنفيذه

### 1) طبقة UX في Design System
- `tokens.ux`: `minTouch` (44)، `pressedOpacity`، مدد حركة مرجعية
- `SkeletonBlock` / `SkeletonCard` / `SkeletonList` — هيكل بدل spinner وحده
- `OfflineBanner` — تنبيه غير متصل واضح

### 2) الرئيسية
- شريط اتصال عند الانقطاع
- هيكل بطاقات أثناء تحميل الإعلانات
- بطل (Hero) أكثر اكتنازاً مع الحفاظ على هوية العلامة
- رد فعل ضغط على الاختصارات السريعة
- أهداف لمس أوضح لأزرار الحساب/البحث/تحميل المزيد

### 3) القوائم والتفاعل
- منتجات / خدمات / مفضلة: هيكل تحميل
- الرسائل: OfflineBanner + هيكل قائمة
- `AdCard` / `CatalogCard`: شفافية ضغط موحّدة + hitSlop للمفضلة
- شريط التنقل: hitSlop خفيف + أيقونات موحّدة

### 4) مبادئ مطبّقة
| مبدأ | تطبيق |
|------|--------|
| أهداف لمس ≥ 44 | tokens + أزرار رئيسية |
| تغذية راجعة فورية | `pressed` على البطاقات/الأزرار/الاختصارات |
| وضوح الحالة | Offline + Skeleton + Empty/Error القائمة |
| تقليل الحمل المعرفي | Hero أخف + أقسام بعنوان موحّد |
