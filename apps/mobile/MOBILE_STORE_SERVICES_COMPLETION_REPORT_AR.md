# تقرير استكمال صفحات المتاجر والخدمات — MarketPlat Mobile

## صفحات المتجر التي أضيفت
- إدارة مجموعات المنتجات: إنشاء مجموعة، إظهارها/إخفاؤها، حذفها، وإضافة منتجات إليها.
- صفحات عرض المجموعات العامة والمنتجات داخل المجموعة.
- إدارة العروض الترويجية: إنشاء خصم بنسبة أو مبلغ، تحديد نافذة زمنية وحد استخدام اختياري، وعرض/إلغاء العروض.
- إدارة فريق المتجر: دعوة مستخدم بالبريد، تغيير الدور، إزالة عضو، وعرض الدعوات الواردة وقبولها.
- إدارة ساعات عمل المتجر لكل يوم عبر `workingHours` المدعوم في API.
- ربط هذه الصفحات من شاشة إدارة المتجر وصفحة المتجر العامة.

## صفحات الخدمات التي أضيفت
- إدارة صور الخدمة: رفع عدة صور، حذف صورة، وإعادة ترتيب الصور (بحد أقصى 10 صور وفق الخادم).
- إحصاءات مقدم الخدمة بفلاتر 7 أيام/30 يومًا/كل الفترة، مع عرض المقاييس والخدمات الأعلى مشاهدة من استجابة API.
- صفحة تقييمات مقدم الخدمة مع تحميل صفحات إضافية وإرسال تقييم مرتبط بمعرّف طلب مكتمل؛ الخادم يبقى المسؤول عن التحقق من الأهلية ومنع التكرار.
- إعداد أنواع الخدمات وخصائص مقدم الخدمة، باستخدام المسارات الموجودة.
- رفع/تغيير شعار مقدم الخدمة.

## واجهات API المستخدمة
استخدمت المسارات الموجودة في `apps/api/src/modules/collections`, `promotions`, `stores` (الأعضاء والساعات)، `service-listings` (الصور)، `service-providers` (الشعار والإحصاءات وأنواع الخدمة)، و`service-reviews`. لم أضف جداول أو مسارات Backend جديدة.

## التحقق
- أضيف `verify-feature-store-services-completion.mjs` إلى `npm test`.
- يجب تشغيل `npm test` و`npm run type-check` من `apps/mobile` بعد تثبيت التبعيات.
- لم يتم تأكيد بناء APK أو اختبار API على خادم وقاعدة بيانات فعلية في بيئة التنفيذ الحالية.

## ملاحظات تشغيلية
- إنشاء العروض يتطلب تاريخي بداية ونهاية بصيغة ISO 8601، ويطبق الخادم قواعد الخصم وتعارض العروض.
- تغيير خصائص نوع الخدمة يتطلب أن يكون لمقدم الخدمة إعلان خدمة من نوع الخدمة المعني، ويُتحقق من مفاتيح الخصائص وقيمها في الخادم.
- تقييم الخدمة يتطلب `requestId` صالحًا لطلب مكتمل ويخص المستخدم؛ لا يُسمح بتقييم عشوائي من الواجهة.
- صلاحيات أعضاء المتجر والتحقق من الملكية تُفرض في Backend، ولا تعتمد الواجهة عليها وحدها.
- أضيفت شاشة مستقلة لساعات عمل مقدم الخدمة، ويمكن تعديلها دون إعادة إرسال بقية بيانات الملف.
- تدعم إدارة المجموعات إعادة تسمية المجموعة، وإدارة عضوية المنتجات للمجموعات النشطة. تحميل عضوية المجموعة يتم عند الطلب لتجنب تنفيذ طلبات API كثيرة عند فتح الشاشة.
- أضيفت شاشة عامة لمجموعات المتجر وصفحة لمنتجات المجموعة، وربطت من صفحة المتجر العامة.
