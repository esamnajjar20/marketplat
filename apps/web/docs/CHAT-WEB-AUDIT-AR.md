# تدقيق نظام الرسائل — الويب

## النتيجة

الويب لم يكن خاليًا من الميزات؛ كان يحتوي بالفعل على إرسال النصوص والصور والصوت والملفات، المسودات والطابور دون اتصال، صفحات الرسائل الأقدم، مؤشرات القراءة والحضور والكتابة، SSE، تثبيت/أرشفة/كتم المحادثة، حظر الطرف الآخر، حذف الرسائل، تثبيت/تمييز الرسائل، ومعرض الوسائط. لكن واجهة الانتظار على سطح المكتب كانت فقيرة، ولم يوجد بحث داخل نص المحادثة، كما أن تحديثات SSE كانت تُبطل قائمة المحادثات مباشرة مع كل رسالة.

## التغييرات المنفذة

1. إضافة بحث داخل الرسائل التي حمّلها المستخدم بالفعل، مع عدد النتائج والتنقل بين النتائج وإبراز النتيجة النشطة واختصاري `Ctrl+F` / `Cmd+F` و`Escape`.
2. توضيح نطاق البحث: لا يدّعي البحث أنه يشمل السجل الكامل؛ حمّل الرسائل الأقدم لتوسيع النطاق. البحث محلي ولا يضيف استعلام قاعدة بيانات.
3. تحسين لوحة سطح المكتب عند عدم اختيار محادثة، بروابط عملية للإعلانات والخدمات وشرح موجز للميزات الحالية، دون استعلامات إضافية.
4. تجميع تحديثات SSE خلال نافذة 500ms بدل إبطال قائمة المحادثات لكل حدث منفرد، وتحديث عدد غير المقروء عند وصول رسالة.
5. عند وصول رسالة إلى المحادثة المفتوحة والمرئية، يجري تحديث واحد مجمّع لسجل الرسائل حتى ينفّذ مسار الخادم الحالي تحديث إيصالات القراءة. لا تُعلَّم محادثة مخفية في الخلفية كمقروءة تلقائيًا.
6. تحديث معاينة المحادثة بعد حذف رسالة.
7. إضافة اختبارات واجهة للبحث وتدقيق ثابت قابل للتكرار.
8. إصلاح عدم اتساق أمني في مسار إرسال الصور: أصبح يمر عبر `requireVerifiedEmail` مثل النص والصوت والملفات، كما كانت التعليقات والسياسة المقصودة توضح.

## مسارات فحص منطق الرسائل

- `apps/web/components/messages/ChatWindow.tsx`: واجهة المحادثة، التصفح بالصفحات، البحث المحلي، حالة الحظر والطابور المحلي.
- `apps/web/components/messages/MessageInput.tsx`: الإرسال والمسودات والمرفقات والصوت والتعامل مع وضع عدم الاتصال.
- `apps/web/hooks/useNotificationStream.ts`: SSE، إزالة التكرار في الكاش، إعادة الاتصال، الأحداث، وتجميع تحديثات القائمة والقراءة.
- `apps/web/hooks/queries/useConversations.ts`: REST وذاكرة IndexedDB والتحميل الاحتياطي دون اتصال.
- `apps/api/src/modules/conversations/conversations.service.ts`: صلاحية أطراف المحادثة، جلب الرسائل وإيصالات القراءة.
- `apps/api/src/modules/conversations/conversations.routes.ts`: المصادقة، حدود المعدل، ومسارات الرسائل والوسائط والإشارات.

## حدود التحقق

تم إجراء تدقيق ساكن على الملفات والربط بين SSE وREST وواجهات الرسائل. لا يمكن اعتبار `tsc` أو Vitest أو اختبار متصفح حقيقي ناجحًا في هذه البيئة لأن تبعيات `node_modules` غير موجودة. يلزم تشغيل `npm run type-check` و`npm test -- --run` من `apps/web`، ثم اختبار متصفحين وحسابين مع شبكة ضعيفة قبل الدمج الإنتاجي.
