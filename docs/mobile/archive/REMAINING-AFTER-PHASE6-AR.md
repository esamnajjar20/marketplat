# ما يبقى بعد المرحلة 6 (خارج نطاق رقعة آمنة)

هذه نقاط من النقد الأصلي **تعذّر إكمالها بالكامل** دون إعادة هيكلة ضخمة أو قرارات منتج:

1. **نقل كل شاشات `app/` (~100) إلى مجموعات** — دليل فقط؛ التنفيذ التدريجي على الفريق.
2. **تقسيم `messages/[id].tsx` و`ad-editor.tsx`** — يحتاج جلسات UI منفصلة مع اختبار يدوي للمحادثة والرفع.
3. **Conflict resolution متعدد الأجهزة** — يتطلب عقد API (vector clocks / updatedAt) من الباكند.
4. **تغطية اختبارات E2E للشاشات** — يحتاج Detox/Maestro وبيئة CI.
5. **Zustand/Redux كامل** — غير ضروري إذا اكتمل TanStack Query + hooks؛ قرار معماري لاحق.
6. **قياس Bundle الفعلي على CI** — يحتاج تشغيل `expo export` في الـ pipeline.

كل البنود القابلة للتنفيذ كملفات رقعة **ضُمّت في المراحل 1–6**.
