# المرحلة 18 — تدقيق التكامل والمزامنة دون اتصال

## ما أضيف
- اختبار تكامل للخادم يرفض تكرار المنتج نفسه كسطرين في سلة نقطة البيع، ويتأكد من عدم إنشاء عملية بيع وعدم تغيير المخزون عند الرفض.
- فحص آلي مستقل لسياسة طابور المزامنة: لا توجد عملية، قيد المعالجة، استنفاد المحاولات، انتظار إعادة المحاولة، عملية مدعومة، وعملية غير مدعومة.
- ربط الفحص الجديد بسلسلة `test` الخاصة بتطبيق الموبايل.
- فحص حواجز الحساب، وملكية الـ lease، وعدم تخزين بيانات الاعتماد، ومفتاح idempotency للمبيعات.

## حدود التحقق
- تم تشغيل فحص المرحلة 18 المستقل باستخدام Node.js.
- اختبار التكامل داخل `apps/api/tests/integration/sales.flow.test.ts` يحتاج قاعدة بيانات اختبار وتهيئة API، ولم يتم تشغيله في هذه البيئة.
- لم يتم تشغيل TypeScript أو بناء Expo؛ لا تعتبر هذه المرحلة اعتمادًا نهائيًا للإصدار.
