# المجموعة 13 — الصفحة الرئيسية والتنقل والاستكشاف

## الملفات المعدلة
- `app/index.tsx` — تحسين المسافات وأحجام عناصر اللمس وبطاقات الإعلانات والتصنيفات والفلاتر.
- `app/my-ads.tsx` — تحسين بطاقة الإعلان وأزرار التعديل والحذف/حفظ طلب الحذف.
- `app/explore.tsx` — تحسين وضوح وجهات الاستكشاف والمسافات وسهولة الوصول للأزرار.
- `app/promoted.tsx` — تحسين حجم معاينات الصور والمسافات داخل بطاقات المنتجات المروجة.

## حدود التغيير
التعديلات مقصودة لتكون بصرية فقط، ولم تتغير مسارات التنقل أو طلبات الشبكة أو منطق المفضلة والفلاتر والحذف.

## التحقق
تم التحقق من وجود الملفات وتضمينها في الأرشيف. لم يتم تشغيل TypeScript أو بناء Expo أو اختبار على جهاز فعلي في هذه البيئة.
