# تقرير ميزة «مبيعاتي» — تطبيق MarketPlat Mobile

## ما أُضيف
- شاشة `app/my-sales.tsx` لعرض ملخص المبيعات حسب اليوم أو الأسبوع أو الشهر أو السنة.
- بطاقات الإيرادات، والمبالغ المحصّلة، والمبالغ المستحقة، وعدد عمليات البيع، وصافي الربح التقديري، والمبالغ المستردة.
- سجل المبيعات مع اسم العميل، والعنصر المباع، ورقم الفاتورة عند توفره، وتاريخ البيع، والكمية، والمدفوع والمتبقي.
- تصفية حسب حالة الدفع: الكل، مدفوعة، مدفوعة جزئيًا، غير مدفوعة، ومتأخرة.
- تحميل الصفحات التالية، والسحب للتحديث، وحالات التحميل والخطأ والنتيجة الفارغة، والتحقق من تسجيل الدخول.
- عميل API جديد `src/features/sales/sales.api.ts` يستعمل مسارات الخادم الحالية `GET /api/v1/sales` و`GET /api/v1/sales/summary` دون تغيير الـ Backend.
- نقطة دخول من الصفحة الرئيسية ومن شاشة إدارة المتجر.
- اختبار تحقق ثابت `scripts/verify-feature-my-sales.mjs` وربطه بأمر `npm test`.

## التمييز المهم
هذه الشاشة تعرض سجلات المبيعات في وحدة المبيعات (`/api/v1/sales`). وهي مختلفة عن «طلبات متجري» التي تعرض طلبات الشراء في نظام التجارة (`/api/v1/orders/seller`). لا تدمج الشاشة إجمالي الطلبات التجارية مع سجل المبيعات، حتى لا تحتسب الإيرادات مرتين أو تخلط بين حالتي دفع مختلفتين.

## التحقق
- اجتازت جميع فحوصات `npm test` الموجودة، بما فيها 10 فحوصات ثابتة خاصة بهذه الميزة.
- لم يُنفّذ فحص TypeScript أو بناء Expo/APK أو اختبار API حي؛ تبعيات `node_modules` غير مثبتة في بيئة العمل. لذلك لا تُعد هذه النتيجة إثباتًا لاختبار التشغيل على جهاز فعلي.
