# المجموعة 11 — تحسين المبيعات والملخصات المالية

## الملفات المعدّلة
- `app/debts.tsx`: توسيع المسافات بين بطاقات ملخص الديون وزيادة وضوح القيم المالية.
- `app/installments.tsx`: تحسين مسافات خيارات التصفية، وتوسيع حقل مبلغ التحصيل ورفع ارتفاعه لتسهيل اللمس.
- `app/customers.tsx`: زيادة التباعد في ملخص العملاء وتحسين إبراز الأرقام والعناوين.
- `app/my-store-analytics.tsx`: توسيع بطاقات المؤشرات وصور المنتجات ومساحة التمرير السفلية.
- `app/service-provider-analytics.tsx`: تحسين تباعد خيارات الفترة وبطاقات المؤشرات وإبراز القيم.
- `app/sale-create.tsx`: زيادة المسافات الداخلية بين عناصر نموذج البيع وبطاقات الأصناف.

## نطاق التغيير
هذه تعديلات عرض وتخطيط محدودة. لم تتغير حسابات الأموال أو قواعد التحصيل أو طلبات API أو منطق حفظ المبيعات والعملاء.

## التحقق
تم فحص وجود الملفات ومساراتها قبل إنشاء الأرشيف. لم يُشغّل TypeScript أو بناء Expo أو اختبار على جهاز فعلي في هذه البيئة؛ لذلك يلزم تشغيل `npm run type-check` واختبارات المشروع قبل اعتماد التغييرات نهائيًا.
