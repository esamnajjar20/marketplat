# تقرير Phase 3 — المتاجر والمنتجات

## النطاق المنفذ
- إضافة طبقة API typed لقراءة المتاجر والمنتجات وتصنيفات المنتجات، وجلب المتجر/المنتج المفرد، وإدارة منتجات المستخدم، وإنشاء/تحديث المتجر والمنتج وحذف المنتج.
- شاشة دليل المتاجر مع البحث والتحديث بالسحب وحالات التحميل والخطأ والفراغ.
- صفحة المتجر العامة مع بيانات المتجر ومنتجاته.
- شاشة دليل المنتجات مع البحث وحالات الواجهة وروابط التفاصيل.
- صفحة تفاصيل المنتج مع الصور المتاحة، السعر الفعلي من `effectivePrice.price`، حالة التوفر ورابط المتجر.
- نموذج إنشاء/تعديل المنتج مع تحميل تصنيفات الخادم والتحقق الأساسي قبل الإرسال.
- شاشة إدارة المتجر لإنشاء/تحديث البيانات الأساسية، وشاشة إدارة منتجات المستخدم مع التعديل والحذف وتأكيد الحذف.
- إضافة مداخل المتاجر والمنتجات وإدارة المتجر ومنتجاتي إلى الصفحة الرئيسية.
- إضافة فحص ساكن Phase 3 إلى أمر `test`.

## قرارات السلامة والتكامل
- لا تنشئ هذه المرحلة مسارات Backend جديدة؛ تستخدم مسارات `/api/v1/stores`, `/api/v1/products`, `/api/v1/product-categories` الموجودة.
- عمليات الإنشاء والتعديل والحذف تستخدم رمز الوصول من `AuthContext` وتترك التحقق النهائي والصلاحيات للخادم.
- لا يجري إظهار نجاح العملية قبل استجابة الخادم.
- شاشة إنشاء المنتج حاليًا لا ترفع صورًا؛ تم إبقاء ذلك صريحًا بدل الإيحاء بأن رفع الصور يعمل قبل تنفيذ تدفق `multipart/form-data` واختباره.
- إدارة المتجر تتطلب ملف بائع (seller profile) وبريدًا موثقًا بحسب قواعد الخادم. إذا لم يكن الحساب مؤهلًا، ستظهر رسالة الخادم ولن يتم تجاوز القيود.

## نتائج التحقق
- `verify-feature-phase3.mjs`: ناجح.

- `verify-feature-phase1.mjs`: ناجح، 5 فحوص ساكنة.
- `verify-scaffold.mjs`: ناجح.
- لم يُشغّل TypeScript كاملًا أو بناء Expo/Android؛ الاعتماديات غير مثبتة في بيئة التدقيق. محاولة `tsc` المباشرة لم تستطع تحميل `expo/tsconfig.base` أو وحدات React Native، لذلك لا تُعتبر بديلًا عن `pnpm --filter @marketplat/mobile type-check` بعد تثبيت الاعتماديات.
- لم يتم إجراء اختبار حي مع API أو جهاز Android.

## تطبيق الحزمة
طبّق ملفات Phase 1 ثم Phase 2 ثم Phase 3 على نفس نسخة المستودع، لأن `app/index.tsx` في هذه الحزمة يتضمن مداخل الميزات السابقة أيضًا.

بعد تثبيت الاعتماديات شغّل:

```bash
pnpm --filter @marketplat/mobile type-check
pnpm --filter @marketplat/mobile test
```

ثم اختبر على جهاز Android: فتح المتاجر والمنتجات، البحث، التفاصيل، إنشاء/تعديل المتجر لحساب مؤهل، إنشاء منتج، تعديل منتج وحذفه. ارفع صور المنتجات واختبرها ضمن مرحلة مستقلة قبل اعتبار دورة الصور مكتملة.
