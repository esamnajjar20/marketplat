# المرحلة الرابعة — مرفقات وصوت محادثات React Native

## ما أُضيف
- تسجيل رسالة صوتية من داخل المحادثة باستخدام `expo-audio`، مع طلب إذن الميكروفون وحدّ تسجيل أقصى 60 ثانية وحدّ رفع 8MB.
- اختيار ملفات من الأنواع التي يسمح بها خادم المحادثات، وبحد أقصى 15MB.
- طابور SQLite دائم للمرفقات، مع نسخ الملف إلى مجلد التطبيق الدائم والتحقق من الحجم بعد النسخ.
- إعادة محاولة إرسال المرفقات عند الاتصال مع تأخير تصاعدي يصل إلى ساعة بين المحاولات، واستخدام `X-Offline-Op-Id` ثابت للعملية المحفوظة لمنع التكرار عند إعادة الطلب.
- حذف نسخة الملف المحلي من الطابور بعد نجاح الإرسال فقط؛ وعند الفشل يبقى الملف محفوظًا مع سبب الخطأ وعدد المحاولات.
- أضيفت حزم Expo المتوافقة مع SDK 58 وإعداد إذن الميكروفون.

## الحدود الحالية
- إعادة المزامنة تعمل عندما تكون شاشة المحادثة نشطة والتطبيق في الواجهة؛ ليست مهمة خلفية مستقلة بعد إغلاق التطبيق.
- لا توجد واجهة لإدارة/حذف المرفقات الفاشلة من قائمة منفصلة بعد؛ تبقى محفوظة ويظهر عدد المرفقات المنتظرة.
- تشغيل الصوت المستلم ما زال يفتح الرابط خارجيًا، وليس مشغلًا صوتيًا مدمجًا.
- لا يمكن تأكيد بناء Expo أو الاختبار على جهاز حقيقي في هذه البيئة؛ يجب تثبيت الحزم ثم تشغيل `npm run type-check` و`npm test` وتجربة حسابين.
