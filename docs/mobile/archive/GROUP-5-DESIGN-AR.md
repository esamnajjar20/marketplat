# المجموعة الخامسة — تصميم إدارة المتاجر والمنتجات والخدمات

## نطاق التعديلات
- `app/my-store.tsx`: تحسين هرمية عنوان إدارة المتجر، إضافة عنوان واضح لقسم أدوات الإدارة، وتطوير بطاقات الانتقال بصريًا.
- `app/my-products.tsx`: تحسين تباعد صفحة المنتجات، تكبير صور البطاقات، وتطوير ظلال البطاقات والعنوان.
- `app/product-editor.tsx`: تحسين المساحة السفلية للنموذج ووضوح عنوانه.
- `app/my-services.tsx`: إضافة وصف تمهيدي يوضح هدف الصفحة.
- `app/service-editor.tsx`: إضافة إرشاد مختصر أعلى نموذج الخدمة.

## حدود التغيير
التعديلات بصرية ونصية فقط. لم تتغير مسارات API أو قواعد التحقق أو عمليات الإنشاء والتعديل والحذف أو منطق الطابور دون اتصال.

## التحقق المنفذ
- `node scripts/verify-feature-store-pages.mjs` — نجح (12 فحصًا).
- `node scripts/verify-feature-store-services-completion.mjs` — نجح (28 فحصًا).
- `node scripts/verify-store-services-audit-fixes.mjs` — نجح (6 فحوص ثابتة).
- فحص تحليل TypeScript/TSX باستخدام `transpileModule` للملفات الخمسة المعدلة — نجح نحويًا.
- لم ينجح فحص الأنواع الكامل `tsc --noEmit` لأن حزم المشروع غير مثبتة (`expo/tsconfig.base` ووحدات React Native غير متاحة في بيئة الفحص). لا يعني ذلك إثبات وجود أخطاء في التعديلات؛ الفحص الكامل ما زال مطلوبًا بعد تثبيت الاعتماديات.
