# المرحلة التالية: المتاجر والقصص في الرئيسية

## التغييرات

- إضافة قسم «متاجر تستحق الاكتشاف» باستخدام واجهة المتاجر العامة الموجودة، مع حد أقصى قدره 6 متاجر وروابط إلى صفحة المتجر وقائمة المتاجر.
- إضافة قسم «قصص وتحديثات جديدة» للمستخدمين المسجلين فقط، مع حد أقصى قدره 8 مجموعات قصص وروابط إلى عارض القصة وصفحة القصص.
- عدم عرض أي قسم فارغ، وعدم السماح لفشل أحد الطلبين بتعطيل بقية الصفحة.
- إضافة تسميات وصول واضحة، ودعم اتجاه RTL، وصور بديلة عند عدم توفر صورة المتجر أو الصورة الشخصية.
- إبقاء الطلبات محدودة: طلب عام واحد للمتاجر، وطلب القصص فقط عند وجود جلسة دخول.

## الملفات

- `apps/mobile/app/index.tsx`
- `apps/mobile/src/features/discovery/HomeCommunitySections.tsx`
- `apps/mobile/scripts/verify-homepage-community-sections.mjs`
- `apps/mobile/package.json`

## التحقق

يجب تشغيل `node ./scripts/verify-homepage-community-sections.mjs` من مجلد `apps/mobile`.
لم يتم اعتبار فحص TypeScript أو بناء Expo ناجحًا دون تشغيله فعليًا.
