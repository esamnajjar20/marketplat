# تقرير إضافة الصفحات المتبقية في تطبيق MarketPlat Mobile

## النطاق

أُضيفت مجموعة الصفحات الناقصة المرتبطة بدورة المبيعات وإدارة الحساب، مع استخدام واجهات API الموجودة في الباك إند وعدم إنشاء endpoints جديدة.

## الصفحات المضافة

1. `app/customers.tsx` — قائمة العملاء، البحث بالاسم/الهاتف، ملخص العملاء، وإضافة عميل.
2. `app/debts.tsx` — إجمالي المستحقات والمتأخرات والمستحق اليوم، قائمة المبيعات المدينة، وتحميل المزيد.
3. `app/installments.tsx` — الأقساط القادمة والمتأخرة وتسجيل تحصيل كلي أو جزئي مع تأكيد المستخدم.
4. `app/activity.tsx` — سجل نشاط الحساب، فلاتر المجموعات، بحث نصي، وترقيم الصفحات.
5. `app/sales/[id].tsx` — تفاصيل البيع، المبالغ، العناصر، الدفعات، الأقساط، ومرجع الفاتورة.
6. `app/sales/[id]/receipt.tsx` — شاشة فاتورة قابلة للعرض داخل التطبيق.

## التكامل

- أُضيفت `src/features/sales/sales-extra.api.ts` لعزل طلبات API والتحقق من أغلفة الاستجابة.
- أُضيفت روابط للصفحات من `my-sales.tsx` والصفحة الرئيسية `index.tsx`.
- أُضيف فحص ثابت `scripts/verify-feature-remaining-account-pages.mjs` وربطه بأمر `npm test`.

## التحقق

- اجتازت سلسلة `npm test` كاملة، بما فيها الفحوصات الثابتة الجديدة.
- لم يُنفّذ TypeScript أو Expo build أو اختبار API حي أو اختبار على جهاز؛ مجلد `node_modules` غير موجود في بيئة العمل.
- شاشة الفاتورة هي عرض داخل التطبيق فقط؛ تصدير PDF والطباعة غير مضافين.
- تسجيل الدفعات يرسل المبلغ الذي يؤكده المستخدم إلى API. يجب التحقق من السلوك الفعلي مع خادم الاختبار قبل الاعتماد الإنتاجي.

## الملفات

الحزمة المصاحبة تحتوي على الملفات المعدّلة والجديدة فقط، مع الحفاظ على المسارات الأصلية.
