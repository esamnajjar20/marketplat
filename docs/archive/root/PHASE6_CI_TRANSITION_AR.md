# المرحلة 6 — انتقال CI إلى Monorepo

## ما تغير
- أضيف فحص ثابت لموضع Prisma والتحقق من المخطط داخل `workspace-foundation-validation.yml`.
- بقيت الوظيفة يدوية (`workflow_dispatch`) لتجنب فرض بوابة جديدة على كل دفع قبل نجاح `pnpm install --frozen-lockfile` في GitHub Actions.
- بقيت الوظائف الحالية التي تستخدم `npm ci` وملفات `package-lock.json` كما هي؛ نقلها جميعًا في خطوة واحدة غير آمن لأن مصدر الحقيقة بين `apps/*` والمجلدات القديمة لم يُحسم بعد.

## ما لم يُدّعَ إنجازه
لم يتم تشغيل GitHub Actions من هذه البيئة، ولم يثبت بعد أن التثبيت المجمد أو البناء الكامل ينجحان. بعد نجاح بوابة التحقق، تُنقل وظائف CI واحدة تلو الأخرى مع مقارنة مخرجاتها قبل حذف الاعتماد على ملفات npm القديمة.
