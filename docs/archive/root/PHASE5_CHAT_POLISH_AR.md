# المرحلة 5 — صقل المحادثة

## ما أُضيف

1. **إخفاء ProtectedHeader + بانر التحقق من البريد** أثناء `/messages/[id]`
   - المحادثة تصبح ملء الشاشة أكثر (أسلوب واتساب)
   - زر الرجوع داخل `ChatWindow` يبقى للتنقل

2. **Haptics عند الإرسال**
   - نجاح / طابور أوفلاين → اهتزاز خفيف
   - فشل → اهتزاز خطأ
   - الملف: `lib/capacitor/nativeHaptics.ts` (`hapticMessageSent` / `hapticMessageError`)
   - مربوط في `MessageInput`

3. **CSS** — `native-app.css` مراحل 1–5

## تثبيت الحزمة

```bash
cd apps/web
npm i @capacitor/haptics
npx cap sync
```

## تحقق على APK

- [ ] فتح محادثة: لا يظهر هيدر الحساب/القائمة العلوية للموقع
- [ ] إرسال رسالة نصية → اهتزاز خفيف
- [ ] فشل إرسال (وضع طيران بدون طابور) → اهتزاز مختلف إن أمكن
- [ ] الرجوع من المحادثة يعيد الهيدر والتنقل السفلي
